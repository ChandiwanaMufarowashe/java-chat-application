# java-chat-application

A Java-based chat application developed during my first year of Computer & Information Science in Application Development at Emeris.

About the Project

This project was created to apply fundamental Java and object-oriented programming concepts in a practical application. It allows users to register and log in, create and manage messages, and perform different operations on stored message data.

Features

* User registration and login
* Username, password and cellphone-number validation
* Message creation and recipient validation
* Unique message ID generation
* Message hash generation
* Send, store or disregard messages
* Search messages by message ID and recipient
* Identify the longest message
* Delete messages using a message hash
* Generate message reports
* Store message information
* Automated testing using JUnit

Technologies

Java 21 • Maven • JUnit 5 • JSON • Object-Oriented Programming

What I Learned

Through this project, I strengthened my understanding of Java programming, arrays, methods, classes and objects, input validation, testing, data handling and problem solving.

Academic Context

This project was developed as part of my first-year programming coursework for my Computer & Information Science in Application Development studies.
